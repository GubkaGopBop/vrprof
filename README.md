# vrprof

Unity-проект учебной профессиональной пробы по обслуживанию ПК. Сценарий: школьник получает результат диагностики, обесточивает виртуальный компьютер, находит неисправный модуль оперативной памяти, заменяет его и повторяет проверку.

## Текущий этап

В `Assets/Scripts` находятся алгоритмы проверки последовательности действий и подготовки сводки. Сцена `Assets/Scenes/PcTrial.unity` показывает компьютер и детали в 3D. Она использует экранные кнопки как временный способ ввода; управление через VR-контроллеры и проверка на шлеме ещё не выполнены. Проект основан на установленном шаблоне Unity 6 `3D Cross Platform`.

## Открытие

1. Открыть эту папку в Unity Hub с редактором 6000.3.9f1.
2. Открыть сцену `Assets/Scenes/PcTrial.unity` и запустить Play Mode. Кнопки слева позволяют выполнить шаги по порядку, выбрать неверный модуль и запросить подсказку.
3. В меню `Tools > VrProf > Проверить алгоритм` запустить два примера и посмотреть результаты в Console.
4. В меню `Tools > VrProf > Проверить Play Mode` запустить автоматический проход сцены. Редактор войдёт в Play Mode, выполнит действия через контроллер, сверит счётчики и состояние корпуса и модулей, затем остановит режим игры.

Скрипты скомпилированы Unity 6000.3.9f1. Проверка двух примеров через метод редактора завершилась с кодом выхода 0: 9/9 шагов с одной подсказкой и одной ошибкой; 4/9 шагов с одной ошибкой. Автоматический проход в Play Mode также завершился с кодом 0: кадры обновлялись, последовательность действий завершена, крышка корпуса закрыта, неисправный модуль скрыт, запасной модуль установлен. Проверочный метод вызывает действия контроллера программно. Управление через VR-контроллеры ещё предстоит реализовать.

В репозитории находятся только файлы Unity-проекта. Отчёт, отдельная консольная программа и временные файлы редактора сюда не входят.
